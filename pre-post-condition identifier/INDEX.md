## 📊 Methodology Summary

### 4-Step Pipeline

```
[INPUT: Breach Description]
    ↓
[STEP A: Keyword Extraction] - Extract attack indicators
    ├─ Input: Unstructured text
    ├─ Output: 11.6 keywords/breach
    ├─ Confidence: 0.843 avg
    └─ Types: action, target, tool, credential
    ↓
[STEP B: TTP Mapping] - Link to MITRE ATT&CK
    ├─ Input: Keywords
    ├─ Output: 3.4 TTPs/breach
    ├─ Coverage: 100%
    └─ Database: 7 techniques
    ↓
[STEP C: Cause-Effect Analysis] - Identify pre/post conditions
    ├─ Pre-Conditions: 11.0/breach (77.5% confidence)
    ├─ Post-Conditions: 10.2/breach (81.5% confidence)
    └─ Total: 106 conditions identified
    ↓
[STEP D: Ranking & Connections] - Prioritize & connect
    ├─ Rank by criticality
    ├─ Connect via shared TTPs
    ├─ Chains: 3.4/breach
    └─ Total: 17 causal chains
    ↓
[OUTPUT: Attack Propagation Analysis]
    ├─ Root causes identified
    ├─ Blast radius calculated
    ├─ Causal chains generated
    └─ Results ranked by criticality
```

- **Confidence**: 77.5% (pre), 81.5% (post)
- **Coverage**: 100% of breaches mapped

## 🛠️ Customization Guide

### Add Keywords
**File:** `security_breach_analysis.py` → `KeywordExtractor`
```python
self.action_keywords = {
    'execute', 'deploy', 'inject', ...  # Add your keywords
}
```

### Add TTPs
**File:** `security_breach_analysis.py` → `TTPMapper._initialize_ttp_database()`
```python
"T99999": TTP(
    ttp_id="T99999",
    name="Custom Technique",
    ...
)
```

**File:** `security_breach_analysis.py` → `CauseEffectAnalyzer`
```python
self.ttp_to_preconditions["T99999"] = [

    "Another precondition"
]
```
